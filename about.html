Behind the shelves

A small library of big imaginations.

The Gilded Library is a Wattpad-inspired storybook website created for the ITE 1 project. It celebrates short fiction with a dark academia visual style: parchment tones, deep shadows, literary typography, and carefully framed cover art.

What you will find

  • Thirty manhwa and novel titles from the selected list, organized by genre.
  • One original fan-made sample chapter per title; these are not official chapters or copied source text.
  • Book cover and supporting scene image for every story.
  • Individual story pages with a shared navigation bar.

Built with

  • HTML5: semantic header, nav, main, section, article, and footer elements.
  • CSS3: shared stylesheet, responsive CSS Grid and Flexbox, hover effects, borders, shadows, and readable typography.
  • JavaScript: dark/light mode, persistent likes, search and genre filtering, synopsis toggle, and reading progress.

How to use the site

Open index.html in a browser. Use the Library page to search or filter books. Select “Read story” to open the matching individual story page. The theme and favorites are saved in your browser using local storage.

Project note

The book titles are from the selected manhwa/novel list. Synopses and sample chapters on this student project site are original fan-made text, not official chapters or a replacement for the published works. Cover and scene illustrations are generated artwork.
